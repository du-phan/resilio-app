# Run Less, Run Faster — source-only methodology record

## Bibliography

- Bill Pierce, Scott Murr, and Ray Moss, *Runner's World Run Less, Run
  Faster*, Rodale.
- Edition, publication year, ISBN, and page/table references must be verified
  from the exact edition before executable use.

## Conceptual scope

The FIRST approach is commonly summarized as three purpose-specific weekly
runs supported by non-running aerobic cross-training. Its exact schedules,
paces, recovery intervals, prerequisites, and cross-training prescriptions
depend on edition-specific tables.

## Resilio boundary

This source record is non-operational. The current repository does not contain
a verified FIRST table implementation, so it must not derive track, tempo, or
long-run paces, substitute generic VDOT paces, or invent cross-sport
equivalences. FIRST selection remains descriptive until its edition-specific
execution evidence and policy are reviewed.
