# 80/20 Running — source-only methodology record

## Bibliography

- Matt Fitzgerald, *80/20 Running: Run Stronger and Race Faster by Training
  Slower*, Penguin Publishing Group, 2014.
- Edition and page/table references have not been verified from a licensed
  local copy.

## Conceptual scope

The book describes a running program in which most training time is low
intensity and a smaller share is moderate or high intensity. The relevant
concept is distribution by training time, not session count, distance, labels,
fitness load, or an average of per-activity polarization indices.

## Resilio boundary

This file is evidence context, not executable policy. It does not authorize an
agent to calculate zones, reconstruct missing provider metrics, classify
completed weeks, or prescribe a universal intensity split.

For a Fitzgerald plan, the athlete-approved macro plan contains an explicit
minimum low-intensity time percentage. The planning policy validates exact
planned run seconds against that approved value. Completed-week analysis uses
covered, primary Intervals.icu time-in-zone evidence and must disclose missing
coverage. Activity-level polarization indices are never averaged into a week.

Pace tables, cross-sport equivalences, field-test protocols, recovery rules,
and workout templates are intentionally absent because no edition-specific
page or table has been verified for executable use.
