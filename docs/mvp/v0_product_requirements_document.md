# v0 product requirements — superseded history

This document records the original product direction and is not operational
guidance. The current product remains a local AI-assisted coach that:

- imports the athlete’s multi-sport activity history;
- computes systemic and lower-body load, fitness, fatigue, form, and readiness
  locally;
- uses evidence-based running methodology and athlete constraints;
- requires explicit VDOT, macro-plan, and weekly-plan approvals;
- publishes only ownership-proven structured workouts.

Current behavior, schemas, and acceptance gates are defined by the
[architecture map](../reference/architecture-map.md), current
[API layer](../specs/api_layer.md), and
[active implementation plan](../plans/2026-07-28-intervals-icu-migration.md).
