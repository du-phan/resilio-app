# v0 user scenarios — superseded history

The durable user journeys from v0 are:

1. Set up a local coaching environment and validate one external account.
2. Import multi-sport history without duplicates.
3. Build a data-grounded athlete profile and goal.
4. Review weekly and multi-week progress.
5. Approve VDOT, macro, and weekly plans in sequence.
6. Adapt training around total load, readiness, injuries, constraints, and
   weather.
7. Publish, update, reschedule, and delete only Resilio-owned workouts.

Use the current [coaching scenarios](../coaching/scenarios.md),
[CLI index](../coaching/cli/index.md), and
[agent workflow](../guides/development/agent-workflow.md) for operational
behavior.
